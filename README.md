# Sthephani Platero | Portfolio

Personal portfolio of Sthephani Yamileth Platero, Full-Stack Developer from El Salvador.
Built with Next.js (App Router), React, TypeScript and Tailwind CSS.

## Pages

- `/` Home: hero with an animated dot-formed title, selected projects.
- `/about` About: bio, technical skills and certifications.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` start the development server
- `npm run build` create the production build
- `npm run start` run the production build
- `npm run lint` run ESLint

## Structure

- `app/` pages, layout, global styles and the `api/hello` route
- `components/` UI components (header, footer, project cards, skills, dot animations)
- `public/` static assets (profile photo)
